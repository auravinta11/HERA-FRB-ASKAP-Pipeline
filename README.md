#  Deep Learning for Fast Radio Burst Detection using Dual Frequency-Time and Dispersion Measure-Time Representations
In this study, we investigate whether combining dispersion measure–time (DM–time) and frequency–time (FT) data enhances the performance of CNNs in distinguishing FRBs from RFI. Simulated FRBs are embedded within radio background data from the HERA telescope, allowing for controlled variation in dispersion measure and signal-to-noise ratio.
